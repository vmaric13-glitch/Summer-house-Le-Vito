## 🚀 Kako Koristiti

1. Otvorite `index.html` u web pregledniku
2. Stranica će se prikazati u punoj funkcionalnosti
3. Svi linkovi za kontakt su aktivni

## ✏️ Prilagodba Stranice

### Promjena Rezervirani Datuma:
U `index.html` pronađite JavaScript sekciju i ažurirajte polje `reserved`:

```javascript
const reserved = [
    new Date(2026, 4, 15),  // Maj 15
    new Date(2026, 4, 16),  // Maj 16
    // Dodajte više datuma...
];
```

### Dodavanje Fotografija:
Zamijenite placeholdere sa pravim fotografijama. Sve slike trebale bi biti:
- Minimalno 800x600px
- Optimizirane za web (do 500KB)
